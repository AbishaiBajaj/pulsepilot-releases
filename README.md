## Installing the early-access version

This version isn't code-signed yet, so your computer may warn you the first time:

- **Windows**: if you see "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac**: open the downloaded file and drag PulsePilot to Applications. If macOS says it can't be opened:
  1. Open **System Settings**, then **Privacy & Security**.
  2. Scroll down to the message about PulsePilot and click **Open Anyway**.
