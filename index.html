Opening PulsePilots for the first time
  • Windows: if you see "Windows protected your PC", click More info → Run anyway. This early-access version isn't code-signed yet.
  • Mac: drag PulsePilots into Applications and open it. If macOS says it can't be opened, go to System Settings → Privacy & Security and click Open Anyway.
  • Linux: right-click the AppImage → Properties → allow running it as a program, then double-click it.
